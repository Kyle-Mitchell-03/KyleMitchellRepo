# Project Descriptions / Instructions

JpnseProject:
This is a simple vocabulary and flashcard service hosted on my own server. I use it to store Japanese vocabulary like Kanji or longer sentence examples I want to reference later. This was my first attempt at creating a live service website that I could access on multiple devices. It's set up using some dependencies: Node for the backend, MYSQL for the database, PM2 for logs, and setting up for tunneling through a Cloudflare domain. 

The project can be accessed through the link: [kom-project.com](https://kom-project.com/)

SP500PredictionProject:
This is a school project I did for a machine learning class. Assuming a user could collect the required data on international indices' performance before the opening of the American Stock Exchange, they could use that information to predict the performance of the S&P 500.

This project was developed in Spyder, a Python IDE, and currently has no front end. Using the supplied CSV and source code, you can recreate the prediction results and metrics for grading accuracy. 

Savor:
This is another school project done for my Senior Design class at CSUN done in collaboration with a few students. While not hosted like my other projects, Savor aimed to be an operational website for restaurants to use to sell stock that was set to expire or be thrown away. Essentially, it functioned like Too Good To Go without the surprise bag element. Restaurant owners would be able to list items for users to buy, and they would have to pick up their order at the restaurant. This was mainly an exercise in understanding the complexity of how applications like DoorDash or Uber function. Firebase was used as a database host to keep everything online for collaborators to view. 

This project was mainly developed on VS Code and ran through Node.js when testing locally. Additionally, we used a reverse proxy service, Ngrok, to host our application when we presented to classmates or judges at panels so they could use a linked QR code to access the application using their phones. 

TripApp:
This is a personal project used for trip itineraries and mapping out activities in given areas. The main functions that it has are a list itinerary with movable activities that can be linked with directions for quick access, a list that automatically sorts uploaded restaurants by proximity to the user, a notes page titled wishlist that serves as a notepad for ideas or important information, and an interactive map using OpenStreetMap. 

This project can be accessed through the link: [tripweb.fyi](https://tripweb.fyi/)
