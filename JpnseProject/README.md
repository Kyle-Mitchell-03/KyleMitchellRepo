# JpnseProject

Japanese vocabulary learning application.

## Requirements

- Node.js
- MySQL

## Installation

Clone repository:

git clone <repository-url>

Install packages:

npm install

## Database Setup

Create MySQL database:

Run:

database/jap.sql


## Environment Variables

Create a `.env` file:

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=password
DB_NAME=vocab


## Running the Project

npm start

Open:

http://localhost:3000
